### **Problem Statement**
Music platforms generate massive amounts of data, making it challenging to quickly identify:
1. [cite_start]The most popular songs and artist trends[cite: 660].
2. [cite_start]The key audio attributes that drive a song's success (e.g., danceability, energy)[cite: 662].

[cite_start]This project tackles the complexity arising from the 120,000 new songs uploaded to music platforms every day[cite: 591, 658].

---

### **Data Source & Scope**

[cite_start]This dashboard is built on a high-quality dataset featuring **953 popular tracks from 2023**[cite: 642].

| Metric Category | Key Data Points |
| :--- | :--- |
| **Track Performance** | Streams, presence in charts, and playlist features. |
| **Audio Attributes** | [cite_start]BPM, key, mode, danceability, valence, and energy [cite: 643, 710-733]. |
| **Contextual Data** | [cite_start]Track name, artist name, release date, and album information [cite: 643, 674-702]. |

---

### **Solution: Power BI Data Dashboard**

[cite_start]We created a visually appealing Power BI dashboard that converts streaming and audio characteristics into clear, actionable business intelligence[cite: 601, 602].

| Solution Component | Description |
| :--- | :--- |
| **Data Visualization** | [cite_start]Highlights key metrics and trends using Power BI, ensuring easy-to-read and visually appealing insights[cite: 602, 603]. |
